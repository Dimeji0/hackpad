Features:
Firmware built using QMK
1. 3 cherry MX style keys
2. EC11 rotary encoder with a switch
3. Xiaou RP 2040
The 3 keys should simply output A,B, and C and then pressing the switch on the encoder will allow it to switch to video playback controls. May not be the final plan for the keys
